Privacy Policy

Home Assistant Calendar Sync. Last updated: 19 September 2026.

What this application is

Home Assistant Calendar Sync is a personal application used by a single person to connect their own Home Assistant installation to their own Google Calendar.

Data accessed

With the owner's consent, the application accesses the owner's Google Calendar data (calendars and events) through the Google Calendar API. It does not access any other Google data.

How data is used

Calendar data is used only inside the owner's own Home Assistant installation, to display events and trigger home automations. It is not used for advertising or analytics.

Storage and sharing

Calendar data and the OAuth access token are stored only on the owner's own Home Assistant device, on the owner's private home network. No data is sold, shared with, or transferred to any third party.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Removing the Google Calendar integration from Home Assistant deletes the stored token and locally held calendar data.
